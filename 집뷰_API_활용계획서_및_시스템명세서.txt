[API 신청 첨부서류] 집뷰(ZipView) 부동산 플랫폼 서비스 기획서 및 API 활용 계획서
================================================================================

1. 서비스 개요
- 서비스명: 집뷰 (ZipView) - 스마트 부동산 실거래·공간정보 플랫폼
- 개발 목적: 아파트, 오피스텔, 원룸/투룸, 빌라/주택 등 주거 유형별 맞춤형 매물 탐색과
             국토교통부 실거래가 시세 추이, 2D 건축 평면도, 3D 방구조 입체뷰를 통합 제공하여
             허위매물을 예방하고 투명한 부동산 거래 환경을 조성함.

2. 주요 기능 구성
(1) 4대 주거 유형별 맞춤 탐색 (첫 화면 카테고리 선택)
    - 아파트 / 오피스텔 / 원룸·투룸 / 빌라·주택 카테고리별 전용 지도 및 필터링 제공
(2) 지도 기반 매물 탐색 및 공간 시각화
    - 지역별(강남·서초, 홍대·마포, 성수·건대, 잠실·송파, 여의도 등) 실시간 매물 마커 표시
    - 거래 유형(월세·전세·매매)별 직관적인 가격 말풍선 및 상세 조건 필터링
(3) 실거래가 데이터 시각화 및 시세 분석
    - 최근 6개월 실거래가 추이 그래프 및 층수별 계약 이력 테이블 제공
    - AI 기반 매물 시세 적정성 및 입지·교통 분석 리포트 제공
(4) 2D 평면도 및 3D 방구조 입체 뷰어
    - 전용면적 기반 2D 치수 평면도 및 360도 회전 가능한 3D 아이소메트릭 방구조 뷰어 제공
(5) 안심 중개사 방문·상담 예약 시스템
    - 실시간 방문 희망일·시간 예약 접수 및 예약 내역 관리 기능

3. 시스템 아키텍처 (백엔드 & 프론트엔드)
- 백엔드(Backend): Node.js RESTful API 서버 (Port 3000)
  * GET  /api/properties       : 유형별·조건별 매물 목록 조회
  * GET  /api/properties/:id   : 매물 상세 정보 및 실거래 이력 조회
  * POST /api/properties       : 신규 매물 등록
  * POST /api/inquiries        : 중개사 방문·상담 예약 등록 및 관리
  * POST /api/ai/chat          : AI 부동산 맞춤 매물 추천
  * POST /api/ai/analyze/:id   : 개별 매물 시세·입지 심층 분석
- 프론트엔드(Frontend): 반응형 웹 애플리케이션 (지도 뷰어, 3D CSS 렌더러, SVG 차트 엔진)
- 데이터베이스(Database): JSON 영구 스토리지 (매물, 회원, 관심매물, 상담예약 테이블)

4. 오픈 API 활용 계획 및 보안 관리 방안
- 활용 목적: 부동산 실거래가 조회, 지도/주소 좌표 변환(지오코딩), 주변 역세권·생활인프라 정보 연동
- 호출 방식: 백엔드 서버(server.js)에서 환경변수(.env)에 API 인증키를 안전하게 보관하고,
             서버 간 통신을 통해 데이터를 수신·가공하여 프론트엔드 화면에 시각화함.
- 보안 대책: 클라이언트 소스코드에 API 키를 노출하지 않으며(.gitignore 적용),
             일일 트래픽 및 호출 횟수를 준수하여 안정적으로 서비스를 운영함.
