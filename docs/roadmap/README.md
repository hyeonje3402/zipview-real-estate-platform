## 버전 표기

저장소의 `package.json`에는 현재 `1.0.0`이 적혀 있습니다. 아래 `v0.2.0`은 제품 릴리스로 확정된 태그가 아니라 **다음 개발 마일스톤 제안**입니다. 실제 공개 버전은 기능 범위와 검증이 끝난 뒤 Git tag와 패키지 버전을 함께 맞춥니다.

## v0.2.0 — 제휴 매물 데이터 흐름 완성 (진행 중)

### 목표

실거래 분석 기능과 현재 거래 가능한 중개사 매물 기능을 명확히 분리하고, 제휴 매물을 안전하게 등록·검수·검색할 수 있도록 합니다.

### 범위

- 실거래 이력과 현재 매물을 분리된 데이터/API로 관리
- 공개 매물 검색에서 지역·유형·거래 조건·키워드 및 페이지네이션 제공
- 관리자 API를 이용한 매물 등록, 검수 대기, 승인·반려·완료 상태 변경
- 공개 승인된 유효 매물만 화면에 노출하고, 미승인·만료 매물은 제외
- 매물 데이터가 없을 때 실거래 이력으로 대체하지 않고 빈 상태를 명확히 표시

### 현재 제한 및 남은 작업

- 매물 검수 API는 `LISTING_ADMIN_API_KEY` 기반으로 보호됩니다. 이 키가 Render에 설정되지 않으면 관리자 API는 사용할 수 없습니다.
- 공인중개사용 로그인, 매물 등록 폼, 사진 업로드, 수정·거래 완료 처리, 검수 화면은 후속 구현 대상입니다.
- 실제 중개사 자료 연동 전 사용 동의, 광고 표시, 개인정보 처리 항목을 확인해야 합니다.
- 운영 환경에서 API·DB·AI 연결과 배포된 화면을 각각 확인해야 합니다.
